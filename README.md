# The KB

**The KB** is my personal site made on the:

**Space theme**

You have a ship, discover all of the planets.

Instead of navigating through a traditional menu, you travel along a path and discover different planets. Each planet represents a different part of me, my work, my interests, and the things I have achieved.

The idea was to make a personal website that feels more like an experience than a normal portfolio. As you move through the site, you discover each section one by one, just like exploring different planets on a journey.

**Planets**

1. Intro — A little about me and this website
2. All About Me — The whole legend behind me
3. Skills — Things I know and things I'm learning
4. Projects — Things I've built
5. Achievements — Things I'm proud of
6. Contact — Where you can find me
7. Blog — Thoughts, experiments, and devlogs

Each planet has its own purpose and is meant to show a different part of my journey. Some sections are still being developed and will change as I add more content to the website.

**Built With**

- HTML
- CSS
- JavaScript
- SVG

The website is built using basic web technologies without relying on a large framework. I wanted to understand how the website works instead of just putting everything together using something I didn't understand.

The path, planets, rocket movement, interactions, and overlays are handled using HTML, CSS, JavaScript, and SVG.

**Status**

The website is a work in progress.

New planets, content, projects, experiments, and improvements will be added over time.

Some parts of the website are still placeholders, while other parts will continue to evolve as I learn and build more things.

**Why I Made This?**

I wanted my personal website to be something different from a normal portfolio.

Instead of having a page with a bunch of sections and links, I wanted the visitor to actually explore the website. The space theme came from that idea: the website is a journey, the planets are the different sections, and the ship takes you through them.

This project is also a way for me to keep improving my web development skills. I expect the design and the way the website works to change a lot as I learn more.

**What I Learned?**

This was my first time making this type of website completely by myself.

I learned HTML, CSS and JavaScript by making this website. A lot of the things I learned came from actually trying to build something, getting stuck, figuring out why it didn't work, and then fixing it.

This project helped me understand how different parts of a website work together, especially when it comes to positioning elements, creating interactions with JavaScript, working with SVG paths, and making a design behave the way I imagined it.

I still have a lot to learn, but this website is where that learning started becoming something I could actually see and interact with.
